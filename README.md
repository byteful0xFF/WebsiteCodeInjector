# WebsiteCodeInjector
:D
---
This allows you to inject code into a website! you can inject html, css, and js. There is example snippets of code.

To use, either use console.js and inject using DevTools, but if you don't have access to that (for example school computer) you can use bookmark.js and copy it into a bookmark and click on the bookmark and boom!
simple enough to use after download.
